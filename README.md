# Web Tasarım

Web Tasarım dersi kapsamında yapılan ders çalışmaları ve dönem projesi:
**ProjeEşleştir — Öğrenci, Mentör ve Proje Eşleştirme Platformu.**

## İçerik

- HTML ile sayfa yapısı
- CSS ile biçimlendirme ve sayfa düzeni (Flexbox, Grid)
- Duyarlı (responsive) tasarım ve erişilebilirlik
- JavaScript ile DOM ve etkileşim
- React ve Supabase ile çalışan bir web uygulaması

## Klasör Yapısı

Hangi haftada ne yapıldığı [PLAN.md](PLAN.md) dosyasında yazılıdır.

```
hafta-01/ … hafta-06/   Haftalık ders çalışmaları (HTML, CSS, JavaScript)
prototip/               Tüm sayfaların ortak stil dosyasıyla birleştirildiği HTML prototipi
uygulama/               React + Supabase ile geliştirilen dönem projesi
```

## Çalıştırma

- **Haftalık çalışmalar ve prototip:** ilgili klasördeki `.html` dosyasını tarayıcıda açmanız yeterlidir.
- **Uygulama:** kurulum, testler ve yayına alma adımları [uygulama/README.md](uygulama/README.md) dosyasındadır.
