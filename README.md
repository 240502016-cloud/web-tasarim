# Web Tasarım

Web Tasarım dersi kapsamında yapılan ders çalışmaları, uygulamalar ve ödevler.

## İçerik

- HTML ile sayfa yapısı
- CSS ile biçimlendirme ve sayfa düzeni
- Duyarlı (responsive) tasarım
- JavaScript ile temel etkileşimler

## Klasör Yapısı

Her haftanın çalışmaları ayrı bir klasörde tutulur:

```
hafta-01/
hafta-02/
...
```

## Çalıştırma

Sayfaları görüntülemek için ilgili klasördeki `index.html` dosyasını bir tarayıcıda açmanız yeterlidir.
